# 心脏 R1：房室瓣的瓣下支撑

[开窗模型](open-wall.glb) · [完整心脏](whole.glb) · [可编辑 Blender 工程](heart-r1.blend)

从开窗模型的二尖瓣或三尖瓣游离缘，沿腱索的分叉向下追到乳头肌，再追到同侧室壁。左室的前外侧、后内侧乳头肌各支持二尖瓣前后两叶；右室的前、后、隔侧乳头肌分别支持三尖瓣的前与后、后与隔、隔与前两叶。两种半月瓣没有腱索。

整心保留四腔与四瓣共 11 片瓣叶。模型中的 5 个乳头肌、10 条腱索主干和 20 个终支均可按名称选取。20 条末支是用于展示连接关系的代表性构型，不是固定解剖数量。开窗件来自同一工程，保留五处肌根的室壁。可在 Blender 4.5 LTS 打开 `.blend`，或将任一 `.glb` 导入三维查看器。

这是一件静态解剖教学模型，不是患者影像重建，也不模拟瓣膜运动或血流。本版是[在线图谱的默认心脏](https://rikka314.github.io/organ-atlas/?organ=heart)；可直接打开[显露心瓣膜](https://rikka314.github.io/organ-atlas/?organ=heart&view=interior)。
